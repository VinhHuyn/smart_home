# Wiki Schema

## Purpose
The wiki is a lightweight index for durable Smart Home project knowledge. It should not duplicate full API docs or changelog entries.

## Page Types
- `entity`: project/component identity.
- `concept`: reusable idea or process.
- `query`: compact answer/history page.

## Rules
- Keep pages short.
- Link to root docs instead of copying them.
- Do not include secrets, Home Assistant auth data, raw state dumps, or token-like values.
- Use `D:\smart_home` / `/mnt/d/smart_home` as the canonical project path.
