## Definition
Documentation sync keeps the Smart Home docs clear, current, and non-duplicative.

## Current Workflow
- Keep one source of truth per topic.
- Put backend endpoints and command examples in `HA_BACKEND_API.md`.
- Put dated changes in `CHANGELOG.md`.
- Put current structure in `PROJECT_TREE.md`.
- Do not store raw Home Assistant state dumps or credential/auth material in docs.
